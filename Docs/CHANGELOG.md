# Changelog

## 0.4.0 — Fidelity pass
- Restored 90-second Crate Crush-style round length.
- Added jump and kick while preserving one-hand mobile controls.
- Removed visible throw trajectory from the runtime bootstrap; aim assist remains invisible.
- Added heavy and gift crates.
- Split TNT and Nitro behavior: TNT fused/carryable; Nitro contact-danger/non-pickable.
- Tuned floor destruction so TNT and Nitro produce distinct hole footprints.
- Added Wumpa-style heal, speed boots, throw boost, shield, slow-zap and falling-weight powerups.
- Added hit stun, hard-hit crate drops, heavy carry penalty and arcade crate lifetimes.
- Improved bot pickup priorities, kick logic and danger jumping.
- Reworked HUD into four-player health/status panels.
- Reworked camera and arena into an original industrial space-station presentation.
- Added four original procedural fighter silhouettes.
- Added procedural original SFX.
- Added fidelity regression gates to `Tools/audit_project.py`.
